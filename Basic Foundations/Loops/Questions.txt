What is the last value alerted by this code? Why?

let i = 3;

while (i) {
  alert( i-- );
}

Last Value is 1. Since the -- is written behind the Variable i it will first give out the current value of i, then reduce it by 1.
So the output would be 3, 2, 1 and since the value becomes 0 the loop stops.
